# Suggested page edits for Baerbel (owner rewrite guide)

Use this when updating **on-page wording**. Search titles and meta descriptions for horse riding / South Island and bike touring stays are already set in the site metadata — you do **not** need to force those phrases into every headline.

Goal: stay on-brand and natural, while helping searchers find Hack n Stay for **horse riding on New Zealand’s South Island**, and helping **bike tourers** find the stay.

---

## Vital principles (please keep)

1. **Keep your voice.** Prefer “holistic horseback experiences”, Hack Track, Patons Rock, Golden Bay — language guests already associate with you.
2. **One job per page.** Horse rides sell rides. Accommodation sells stays (including bike tourers). Don’t lead the rides page with cycling.
3. **Say it once, clearly.** One natural South Island / location sentence beats repeating “horse riding South Island New Zealand” everywhere.
4. **Title tags can differ from the H1.** Search listings may say “Horse Riding South Island New Zealand | Hack n Stay Golden Bay” while the page hero stays “Holistic Horseback Experiences”. That is fine.
5. **Don’t keyword-stuff.** If a sentence sounds like an ad, rewrite it until it sounds like you.
